## Long Description (4000 chars, keyword density 3-5x)
Link Saver is a fast bookmark manager and read later app that also protects your links.

Save links from any app in one tap — articles, videos, products, GitHub repos, YouTube, Reddit, Medium — and organize them with collections, categories, tags and favorites.

Unlike basic bookmark managers, Link Saver checks for broken links and dead pages. When a link dies, it finds a Wayback Machine archive and keeps an offline snapshot of the text so you never lose it.

Key features:
- Save links & bookmarks from any app (share sheet + clipboard)
- Bookmark manager with collections, categories, tags, search & filters
- Broken link checker — detect dead links in batches, see status history
- Wayback archive finder & auto-archive — restore dead pages
- Offline snapshot — read saved articles even when the original is gone
- Forgotten links — resurface links you haven't opened in 30 days
- Reminders & snooze with notifications
- Stats — read rate, dead rate, platform breakdown
- Android widget — see recent & dead links on your home screen
- Private & offline-first — no account, data stays on your device
- Export / import — JSON, Markdown, CSV, HTML backup
- 12 languages, 3 themes, 3 card sizes

Perfect as a read later app, link saver, and bookmark manager that also works as a broken link checker and Wayback archive tool.
